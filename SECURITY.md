# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use a
private GitHub security advisory or contact the project maintainer through the
repository profile.

Include the affected version, macOS version, reproduction steps, and any
relevant logs. Do not include passwords, signing credentials, private profiles,
or other sensitive data.

Tenuo requires Accessibility access because it installs a system-wide
keyboard event tap. It is intentionally not sandboxed. Source builds have no
update feed configured by default.
