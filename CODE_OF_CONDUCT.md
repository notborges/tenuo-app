# Code of Conduct

Tenuo is a small project, and every contributor is expected to be respectful,
constructive, and patient.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disruption, and publishing someone else's private information.

Maintainers may remove comments, close issues, or block participation when
necessary to keep the project safe and useful. Report conduct concerns privately
to the project maintainer rather than opening a public issue.
